# API жобасы (6-сабақ)

| Әдіс | Жол | Кім | Не істейді | Story | Кесте |
|---|---|---|---|---|---|
| GET | /api/subjects | student, teacher | Пәндер тізімін көру (Получить список предметов) | US-1 | subjects |
| POST | /api/quizzes | teacher | Жаңа тест құру (Создать тест) | US-1 | quizzes |
| GET | /api/quizzes | student, teacher | Қолжетімді тесттер тізімі (Список доступных тестов) | US-1 | quizzes |
| GET | /api/quizzes/{id} | student, teacher | Тест ақпаратын қарау (Просмотр деталей теста) | US-1 | quizzes |
| POST | /api/quizzes/{id}/questions | teacher | Тестке сұрақ қосу (Добавить вопрос к тесту) | US-2 | questions |
| GET | /api/quizzes/{id}/questions | teacher, student | Тест сұрақтарын алу (Получить вопросы теста) | US-2 | questions |
| POST | /api/quizzes/{id}/attempts | student | Тестті тапсыру / жауаптарды жіберу (Пройти тест / отправить ответы) | US-3 | attempts |
| GET | /api/attempts/{id} | student (иесі), teacher | Тапсыру нәтижесін және балын көру (Просмотр результатов попытки) | US-3 | attempts |
| GET | /api/students/me/attempts | student | Өз тапсыру тарихын көру (История своих попыток) | US-3 | attempts |

> **Тексеру (Чек-лист):**
> - [x] Әр Must story-де кемінде бір endpoint бар (US-1, US-2, US-3).
> - [x] Барлық жолдар `/api/`-дан басталады.
> - [x] «Кесте» бағанындағы кестелердің барлығы `er-diagram.md`-де бар (`subjects`, `quizzes`, `questions`, `attempts`).
> - [x] «Кім» бағанында рөлдер нақты жазылған (`student`, `teacher`, `иесі`).

## Жауап кодтары

| Код | Атауы | Мағынасы | Қашан қайтарылады |
|---|---|---|---|
| **200** | OK | Сәтті (Успешно) | GET сұраныстары бойынша деректер сәтті алынғанда |
| **201** | Created | Құрылды (Создано) | POST арқылы жаңа тест, сұрақ немесе тапсыру әрекеті жасалғанда |
| **400** | Bad Request | Қате сұраныс (Неверный запрос) | Сұрақтар саны сәйкес келмегенде немесе жауаптар қате пішімде болғанда |
| **401** | Unauthorized | Авторизацияланбаған | Пайдаланушы жүйеге кірмегенде (Keycloak токені жоқ немесе жарамсыз) |
| **403** | Forbidden | Рұқсат жоқ (Доступ запрещен) | Студент тест құрмақшы болғанда немесе біреу өзгенің нәтижесін көрмекші болғанда |
| **404** | Not Found | Табылмады (Не найдено) | Сұралған ID бойынша тест, сұрақ немесе нәтиже табылмағанда |
| **422** | Unprocessable Entity | Валидация қатесі | Деректер схема талабына сай болмағанда (тақырып тым қысқа, ұпай теріс сан және т.б.) |
| **500** | Internal Server Error | Сервер қатесі | Деректер базасында немесе серверде күтпеген қате орын алғанда |
