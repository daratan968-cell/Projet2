# Проект API (Урок 6)

| Метод | Путь | Кто | Что делает | Story | Таблица |
|---|---|---|---|---|---|
| GET | /api/subjects | student, teacher | Получить список предметов | US-1 | subjects |
| POST | /api/quizzes | teacher | Создать новый тест | US-1 | quizzes |
| GET | /api/quizzes | student, teacher | Список доступных тестов | US-1 | quizzes |
| GET | /api/quizzes/{id} | student, teacher | Просмотр деталей теста | US-1 | quizzes |
| POST | /api/quizzes/{id}/questions | teacher | Добавить вопрос к тесту | US-2 | questions |
| GET | /api/quizzes/{id}/questions | teacher | Просмотр вопросов теста | US-2 | questions |
| POST | /api/quizzes/{id}/attempts | student | Пройти тест / отправить ответы | US-3 | attempts |
| GET | /api/attempts/{id} | student (автор), teacher | Просмотр результатов попытки и оценки | US-3 | attempts |
| GET | /api/users/me/attempts | student | История своих попыток сдачи | US-3 | attempts |

> **Чек-лист проверки:**
> - [x] Для каждой Must story есть как минимум один эндпоинт (US-1, US-2, US-3).
> - [x] Все пути начинаются с `/api/`.
> - [x] Все таблицы присутствуют в `er-diagram.md` (`subjects`, `quizzes`, `questions`, `attempts`).
> - [x] В колонке «Кто» чётко указаны роли (`student`, `teacher`, `автор`).

## Коды ответов

| Код | Название | Значение | Когда возвращается |
|---|---|---|---|
| **200** | OK | Успешно | Данные успешно получены по GET-запросу |
| **201** | Created | Создано | Успешно создан новый ресурс (тест, вопрос, попытка) через POST |
| **400** | Bad Request | Неверный запрос | Несоответствие количества ответов или неверный формат данных |
| **401** | Unauthorized | Не авторизован | Пользователь не вошёл в систему (токен Keycloak отсутствует или недействителен) |
| **403** | Forbidden | Доступ запрещён | Студент пытается создать тест или пользователь пытается просмотреть чужой результат |
| **404** | Not Found | Не найдено | Тест, вопрос или результат с указанным ID не найден |
| **422** | Unprocessable Entity | Ошибка валидации | Данные не прошли валидацию Pydantic (слишком короткий заголовок, отрицательный балл и т.д.) |
| **500** | Internal Server Error | Ошибка сервера | Непредвиденная внутренняя ошибка базы данных или сервера |
